# Spaceship-Titanic

Proyek ini bertujuan untuk mengembangkan model klasifikasi prediktif yang mampu mengidentifikasi probabilitas penumpang terlempar ke dimensi alternatif akibat anomali ruang-waktu pada insiden Spaceship Titanic. Analisis dilakukan terhadap dataset yang mencakup rekam medis serta metrik perjalanan dari 8.693 penumpang. Untuk mengatasi tantangan data yang hilang dan distribusi yang tidak seimbang, kami menerapkan alur prapemrosesan sistematis meliputi imputasi logis, imputasi K-Nearest Neighbors, serta winsorizing. Tahap feature engineering berhasil mengekstraksi 45 fitur berdimensi tinggi dari data dasar. Berkaca pada kompleksitas data, kami memperluas rancangan awal dari tiga model menjadi tujuh pendekatan machine learning untuk mendapatkan evaluasi komparatif yang ketat, yaitu XGBoost, LightGBM, Random Forest, Extra Trees, CatBoost, Shallow Neural Network, dan Stacked Ensemble. Pengujian empiris pada himpunan data validasi menunjukkan bahwa XGBoost meraih akurasi tertinggi sebesar 81,60%. Akan tetapi, pada blind test melalui public leaderboard Kaggle, CatBoost menunjukkan kapabilitas generalisasi terbaik dengan skor 81,22%. Temuan ini mengindikasikan bahwa model berbasis pohon, khususnya yang memiliki penanganan kategorikal bawaan, sangat kokoh untuk permasalahan data tabular dengan rasio kardinalitas yang bervariasi.
